Leitor de Chaves NF-e

Envie as imagens dos DANFEs. O leitor localiza a chave de 44 dígitos logo abaixo do código de barras, gira a imagem quando necessário e só apresenta uma chave depois de confirmá-la pelo dígito verificador oficial (módulo 11). Se a leitura não puder ser confirmada com segurança, a nota é sinalizada como erro — nenhum dígito é adivinhado.

Dica: se aparecer erro ao carregar o motor de OCR dentro da pré-visualização do chat, baixe este arquivo e abra-o direto no seu navegador (duplo clique) — a rede do seu computador não tem a mesma restrição do painel de pré-visualização.

      Notas com a mesma chave

        Como funciona a verificação: os 43 primeiros dígitos de toda chave de NF-e determinam matematicamente o 44º dígito (o dígito verificador), pelo algoritmo módulo 11 definido pela SEFAZ. Uma chave só é aceita aqui se essa conta bater — por isso a leitura é confiável mesmo quando a imagem está torta, com pouca luz ou baixa resolução: se o OCR errar um dígito, a verificação falha e a nota vai para "erro" em vez de mostrar um número incorreto.
